## activedirectory

管理和查询 **Microsoft Active Directory (AD)** 的专用工具。它是 Windows 域环境中执行 AD 相关操作的核心命令。 控制域控制器，没有实验成功。

```
指令：
help  activedirectory
[06:51:44] ID: 686 'help' started [target: z0.0.0.11]
Usage: activedirectory _Options_
   Queries the active directory global catalog
   
   <-mode> (group=options)
      Retrieves the mode of an Active Directory server
   <-computers> (group=options)
      Returns the list of computers currently listed in the GC
   <-groups> (group=options)
      Returns the list of groups currently listed in the GC
   <-users [user]> (group=options)
      Returns the information on the user or all users listed in the GC
   [-verbose]
   [-pagesize <pagesize>]
      Sets the number of entries used per page
   [-adspath <path>]
      Specifies the path of the catalogy to query.
      Default is 'LDAP:'
      
解释：
activedirectory
-mode	主操作	获取AD服务器运行模式	activedirectory -mode
-computers	主操作	获取所有计算机列表	activedirectory -computers
-groups	主操作	获取所有组列表	activedirectory -groups
-users [user]	主操作	查询指定用户或所有用户	activedirectory -users admin
-verbose	选项	显示详细输出信息	-verbose
-pagesize <N>	选项	设置分页查询条目数	-pagesize 100
-adspath <path>	选项	指定目录查询路径	-adspath "LDAP://dc01.domain.com"

   ```

   ```
   # 在自动化脚本中替代硬编码路径

### 15、`strings` 命令速查表

#### **命令用途**

`strings` 用于从 **二进制文件** 或 **内存转储** 中提取可读字符串，主要功能包括：

1. 分析可执行文件、库、驱动中的字符串
2. 搜索内存转储中的敏感信息
3. 逆向工程和取证分析

------

### **基本命令格式**

```
strings <文件路径> [选项]
```

#### **核心参数**

| 参数            | 说明                                     | 默认值   | 示例                    |
| :-------------- | :--------------------------------------- | :------- | :---------------------- |
| `<nameAndPath>` | 要分析的文件路径                         | 必填     | `strings /bin/ls`       |
| `-threshold`    | 最小字符串长度                           | `4`      | `-threshold 8`          |
| `-max`          | 最大返回字符串数                         | 无限制   | `-max 100`              |
| `-radix`        | 显示文件偏移量（十进制/十六进制/八进制） | 无       | `-radix hex`            |
| `-encoding`     | 字符编码（ASCII/Unicode）                | `ASCII`  | `-encoding Unicode`     |
| `-bounds`       | 指定搜索范围（起始偏移 [结束偏移]）      | 整个文件 | `-bounds 0x1000 0x2000` |

------

### **使用示例**

1. **基本提取（ASCII字符串）**

   ```
   strings malware.exe
   ```

2. **提取Unicode字符串（如PE文件中的宽字符）**

   ```
   strings target.dll -encoding Unicode
   ```

3. **带偏移量显示（十六进制格式）**

   ```
   strings /bin/bash -radix hex -threshold 6
   ```

   **输出示例**：

   ```
   0x1A3F: /lib64/ld-linux-x86-64.so.2
   0x1B20: GLIBC_2.2.5
   ```

4. **限制搜索范围和输出数量**

   ```
   strings memory.dmp -bounds 0x400000 0x500000 -max 50
   ```

------

### **高级技巧**

#### **1. 结合管道过滤敏感信息**

```
strings ransomware.bin | grep -i "password\|key"
```

#### **2. 批量分析目录下所有文件**

```
find /opt/app -type f -exec strings {} \; > strings_report.txt
```

#### **3. 取证分析（提取HTTP URL）**

strings browser_cache.dat | grep -E "http[s]?://"

serialredirect <-连接类型> [参数]

   ```

### `32、redirect` 命令速查表

#### **命令用途**

`redirect` 提供 **TCP/UDP 数据包转发**功能，实现类VPN的通信隧道，支持：

1. **端口监听与转发**（本地↔远程）
2. **协议选择**（TCP/UDP）
3. **连接数控制**与 **IP范围限制**

------

### **核心参数**

#### **1. 协议选择（必选其一）**

| 选项   | 说明                    |
| :----- | :---------------------- |
| `-tcp` | 使用TCP协议（可靠传输） |
| `-udp` | 使用UDP协议（低延迟）   |

#### **2. 监听配置（必选其一）**

| 选项             | 语法              | 说明                    |
| :--------------- | :---------------- | :---------------------- |
| `-lplisten`      | `<端口> [绑定IP]` | 在**本地LP端**监听      |
| `-implantlisten` | `<端口> [绑定IP]` | 在**远程Implant端**监听 |

#### **3. 目标转发（必选）**

| 选项      | 语法                                  | 说明           |
| :-------- | :------------------------------------ | :------------- |
| `-target` | `<目标IP> <目标端口> [源IP] [源端口]` | 指定转发目的地 |

------

### **常用选项**

| 选项                | 说明                               | 示例                                          |
| :------------------ | :--------------------------------- | :-------------------------------------------- |
| `-connections`      | 最大并发连接数（0=无限制）         | `-connections 10`                             |
| `-limitconnections` | 限制允许连接的IP范围               | `-limitconnections 192.168.1.0 255.255.255.0` |
| `-packetsize`       | 单次传输数据包大小（默认8192字节） | `-packetsize 4096`                            |
| `-sendnotify`       | 向连接方发送成功/失败通知          | `-sendnotify`                                 |

------

### **使用示例**

#### **1. TCP端口转发（本地→远程）**

```
redirect -tcp -lplisten 8080 -target 10.0.0.5 80  
```

**功能**：将本地`8080`端口的TCP流量转发到`10.0.0.5:80`

#### **2. UDP数据转发（远程→本地）**

```
redirect -udp -implantlisten 5353 -target 192.168.1.100 53  
```

**功能**：将远程`5353`端口的UDP流量转发到本地`192.168.1.100:53`

#### **3. 高级控制（限制IP+连接数）**

```
redirect -tcp -lplisten 3389 -target 172.16.1.1 3389 \  
         -limitconnections 10.0.0.0 255.0.0.0 \  
         -connections 5  
```

**功能**：仅允许`10.0.0.0/8`网段连接，最多5个并发

### 33、命令分析：`registryadd`

#### 选项解析

   - 作用：定义值的格式，需与 `-data` 参数匹配。

### 71、命令分析：moduletoggle

**功能**：更改或管理目标系统中的实现模块（implementation modules），包括列出可用模块、设置特定模块实现、注册模块或加载模块。

**用法**：`moduletoggle _Options_`

#### 选项解析

1. **`-system <name>`** (可选)
   - 指定要检查或更改的系统名称。
   - 作用：定义操作的目标系统（如某个子系统或服务）。
   - 示例：`-system network` 表示操作与网络相关的模块。
2. **`-list`** (可选，group=action)
   - 列出可用系统或指定系统的可用实现模块。
   - 作用：
     - 若未指定 `-system`，列出所有可用系统。
     - 若指定 `-system`，列出该系统的可用实现模块。
   - 示例：`-list` 列出所有系统，或 `-system network -list` 列出网络系统的实现模块。
3. **`-set <impl>`** (可选，group=action)
   - 设置指定系统的实现模块。
   - 作用：将目标系统的实现切换为指定的模块。
   - 示例：`-system network -set default` 表示将网络系统的实现设置为 `default`。
4. **`-register`** (可选，group=action)
   - 注册指定系统的实现模块。
   - 作用：将模块注册到系统中，使其可用于后续操作。
   - 示例：`-system network -register` 注册网络系统的实现模块。
5. **`-silent`** (可选)
   - 禁止显示命令输出。
   - 作用：执行操作时不返回详细信息，适合脚本自动化。
   - 示例：`-silent` 表示不显示输出。
6. **`-load`** (可选)
   - 加载指定的实现模块。
   - 作用：将模块加载到内存以供使用。
   - 示例：`-load` 表示加载模块。
7. **`-nofree`** (可选)
   - 不释放相关实现模块。
   - 作用：防止卸载与目标系统相关的其他模块，保留现有模块状态。
   - 示例：`-nofree` 表示不释放相关模块。

### 72、命令分析：move

**功能**：将指定的源文件移动到目标位置，可选择在系统重启后执行移动操作。

**用法**：`move <srcFile> <dstFile> _Options_`

#### 参数解析

1. **`<srcFile>`** (必选)
   - 指定要移动的源文件路径。
   - 作用：定义需要移动的文件，可以是相对路径或绝对路径。
   - 示例：`C:\Logs\system.log` 表示移动 `C:\Logs\system.log` 文件。
2. **`<dstFile>`** (必选)
   - 指定目标文件路径。
   - 作用：定义文件移动后的新位置和名称。
   - 示例：`C:\Archive\system.log` 表示将文件移动到 `C:\Archive\system.log`。

#### 选项解析

1. **`-afterreboot`** (可选)
   - 在系统重启后执行文件移动操作。
   - 作用：延迟文件移动，适用于文件被锁定或系统限制的情况。
   - 示例：`-afterreboot` 表示文件将在下次系统重启时移动。
