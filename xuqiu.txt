九、交互动画与动态视觉设计（重点要求）

你是一名资深交互设计师和前端动效工程师。

请为「三藏の博客」设计一套完整的科技风交互动画系统。

核心设计理念：

- 动效服务于交互，而不是单纯装饰。
- 动画需要有层次感、空间感和物理反馈。
- 保持暗黑科技风，青绿色作为主要动态强调色。
- 动画流畅、克制、精致，避免廉价的赛博朋克视觉。
- 所有动画必须真正实现，不能只提供静态效果。

1. 页面背景动态效果

星空粒子系统

在首页 Hero 区域和部分背景区域实现轻量粒子效果。

要求：

- 深色背景中存在少量缓慢移动的星点。
- 星点亮度随机变化。
- 偶尔出现细微流星划过。
- 鼠标移动时，附近粒子产生轻微响应。
- 粒子之间可以通过微弱连线形成数字网络效果。
- 不要覆盖主要文字和文章卡片。

动态网格背景

在部分暗色区域加入科技网格：

- 使用 CSS 渐变或 SVG 绘制网格。
- 网格具有非常缓慢的移动效果。
- 局部区域出现低亮度青绿色扫描光。
- Hover 时局部网格亮度轻微增强。

注意：粒子数量必须控制，避免影响低配置设备性能。

2. Sidebar 导航交互

导航栏实现以下动画：

- 当前菜单具有青绿色渐变高亮背景。
- 左侧出现动态指示线。
- 当前图标具有轻微缩放和亮度变化。
- 鼠标悬停时图标产生微小位移动画。
- 点击切换时高亮背景平滑移动到新菜单。
- 导航切换时页面内容采用淡入和轻微位移动画。

导航栏收缩功能：

- 点击收缩按钮，导航栏从 200px 平滑收缩至 72px。
- 图标保留，文字淡出。
- Hover 时可以通过 Tooltip 显示菜单名称。
- 再次点击恢复完整导航。

3. 顶部搜索交互动画

搜索框需要具有类似现代 IDE 的交互体验。

默认状态：

- 深色半透明背景。
- 细微边框。
- 搜索图标。

Focus 状态：

- 边框逐渐变成青绿色。
- 出现柔和的外发光。
- 搜索框轻微扩大。
- 背景透明度发生变化。

搜索面板：

- 使用 Framer Motion 实现向下展开。
- 搜索结果逐项淡入。
- 关键词匹配部分高亮。
- 搜索历史可以折叠展示。
- 按下 Esc 平滑关闭。
- 按下 Ctrl+K / Cmd+K 快捷键打开。

4. Hero Banner 视觉动画

Hero 是首页最重要的视觉中心。

背景视差

实现多层视差效果：

- 远景星空。
- 中景行星。
- 近景山脉或科技建筑。
- 不同图层使用不同移动速度。
- 鼠标移动时产生微妙的空间位移。

移动端禁用复杂鼠标视差。

文字入场

页面首次加载：

- 主标题从下方轻微上移并淡入。
- 副标题延迟 150ms 出现。
- CTA 按钮延迟 300ms 出现。
- 使用自然缓动曲线。

CTA 按钮

- Hover 时青绿色边框逐渐发光。
- 箭头向右移动 4px。
- 背景出现轻微流动渐变。
- 点击时产生轻微缩放反馈。

轮播

- 图片切换使用交叉淡入和轻微缩放。
- 文字同步切换。
- 底部指示器具有平滑进度动画。
- 自动播放间隔建议 6 秒。
- 鼠标悬停时暂停自动播放。
- 用户手动切换后重置计时。

5. 文章卡片交互动画

每篇文章卡片都需要有精致的动态反馈。

默认状态：

- 深色玻璃质感。
- 细微边框。
- 图片与内容层次分明。

Hover 状态：

- 卡片向上移动 5px。
- 卡片边框逐渐变亮。
- 阴影向外扩散。
- 封面图片放大至 1.05 倍。
- 分类标签产生轻微亮度变化。
- 文章标题颜色向青绿色过渡。
- 右下角阅读箭头逐渐显现。

点击状态：

- 卡片轻微缩小。
- 页面进入文章详情页时使用淡出过渡。

文章列表入场：

- 使用 Stagger 动画。
- 卡片按照顺序依次出现。
- 每张卡片延迟约 80ms。
- 不要让大量文章同时产生明显位移。

6. 个人信息卡动画

个人头像：

- 外围青绿色圆环缓慢旋转。
- 在线状态圆点具有柔和呼吸效果。
- Hover 时头像轻微放大。

数据统计：

- 文章数量、阅读量使用数字递增动画。
- 数字只在首次进入可视区域时触发。
- 不要在每次滚动时重新播放。

社交图标：

- Hover 时向上移动 3px。
- 图标亮度增强。
- 点击时提供缩放反馈。

7. 热门标签动画

- 标签 Hover 时背景颜色逐渐变化。
- 标签轻微上浮。
- 青绿色边框渐显。
- 点击后产生轻微缩放反馈。
- 被选中的标签保持高亮。
- 标签切换文章列表时使用淡入淡出动画。

8. 近期动态时间轴动画

- 时间轴线从上至下逐渐绘制。
- 节点按照时间顺序依次出现。
- 节点进入可视区域时产生轻微缩放。
- 最新动态节点可以有柔和呼吸效果。
- Hover 时对应动态卡片轻微高亮。

9. 页面路由转场动画

实现全站统一的路由过渡。

进入新页面：

- 旧页面轻微淡出。
- 新页面从下方 12px 位置淡入。
- 动画持续 250～350ms。

文章详情页：

- 文章标题先出现。
- 封面图片随后淡入。
- 正文采用分段渐入。
- 目录导航保持固定。
- 阅读进度条随着滚动更新。

返回文章列表：

- 保持合理的滚动位置。
- 尽可能恢复之前的浏览状态。

10. 文章详情页交互动画

阅读进度条

- 页面顶部显示一条青绿色进度线。
- 随文章阅读进度动态增长。
- 到达文章末尾时达到 100%。

目录导航

- 当前阅读章节自动高亮。
- 激活章节具有青绿色指示线。
- 点击目录平滑滚动至对应标题。
- 目录支持折叠和展开。

代码块

- 代码块采用深色 IDE 风格。
- Hover 时工具栏显示。
- 点击复制按钮后显示复制成功状态。
- 复制按钮图标在成功时平滑切换。
- 代码块支持展开和折叠。

图片预览

- 点击文章图片打开 Lightbox。
- 背景逐渐变暗。
- 图片从原始位置平滑放大至居中。
- 支持 ESC 关闭。
- 支持左右切换图片。
- 支持鼠标滚轮缩放或按钮缩放。

11. 页面滚动动画

采用 IntersectionObserver 实现滚动触发动画。

适用模块：

- 最新文章。
- 精选推荐。
- 个人资料。
- 热门标签。
- 近期动态。

动画规范：

- 从下方 16px 淡入。
- 透明度从 0 过渡到 1。
- 不同模块错开触发。
- 元素离开屏幕后不需要反复执行入场动画。

12. 鼠标交互效果

实现克制的科技风鼠标反馈：

- 交互元素 Hover 时光标状态变化。
- 卡片可以具有轻微的 3D Tilt 效果。
- 3D 倾斜最大角度控制在 3 度以内。
- 卡片边缘出现跟随鼠标位置的微弱青绿色光效。
- 鼠标离开后恢复初始状态。
- 不要使用大面积跟随鼠标的光球。

移动端不启用鼠标跟随和 3D Tilt。

13. 主题切换动画

支持暗色与亮色主题。

切换时：

- 页面背景平滑过渡。
- 卡片颜色平滑过渡。
- 文字颜色平滑过渡。
- 边框和阴影同步变化。
- 切换按钮图标旋转并过渡。
- 保存用户主题选择。

默认主题必须是暗黑科技风。

14. 加载动画与空状态

页面初始加载：

- 使用简洁的品牌 Logo 动画。
- Logo 由线条逐步绘制。
- 随后显示博客首页。
- 不要使用长时间的加载动画。

图片加载：

- 使用骨架屏。
- 图片加载完成后淡入。
- 加载失败时显示统一的科技风占位图。

搜索无结果：

- 显示简洁的空状态插画。
- 提供清除搜索按钮。

文章列表为空：

- 显示友好的空状态提示。

15. 动画技术规范

推荐技术：

- Motion（Framer Motion 现代版本）：组件动画和路由过渡。
- CSS Transitions：基础 Hover 和颜色过渡。
- CSS Keyframes：持续呼吸、扫描线、背景动画。
- IntersectionObserver：滚动触发。
- requestAnimationFrame：必要的鼠标视差和高频动画。

统一动画参数：

动画类型| 建议时长
Hover| 150～220ms
按钮反馈| 120～180ms
卡片动画| 200～300ms
面板展开| 250～350ms
页面切换| 250～350ms
背景循环动画| 8～20s
呼吸动画| 3～5s

统一使用自然缓动，不要所有动画都采用线性过渡。

16. 性能与无障碍要求

1. 优先使用 transform 和 opacity。
2. 避免频繁触发页面重排和重绘。
3. 使用 IntersectionObserver 减少不必要的动画。
4. 使用 requestAnimationFrame 控制高频鼠标动画。
5. 页面切换时及时清理事件监听。
6. 离开页面后停止不必要的循环动画。
7. 支持 prefers-reduced-motion。
8. 用户开启减少动态效果时，禁用视差、粒子和复杂入场动画。
9. 移动端自动降低粒子数量。
10. 动画不能影响文字可读性和正常操作。

17. 动效验收标准

请逐项检查：

- Sidebar 菜单切换是否流畅。
- 导航栏收缩是否正常。
- 搜索框展开和关闭是否自然。
- Hero 视差是否具有空间感。
- 文章卡片是否有完整 Hover 效果。
- 页面滚动动画是否按需触发。
- 个人头像和数字统计动画是否正常。
- 路由切换是否平滑。
- 文章目录和阅读进度是否同步。
- 图片 Lightbox 是否正常。
- 暗色和亮色主题切换是否正常。
- 移动端是否关闭不必要的复杂动画。
- 减少动态效果设置是否生效。

最终目标：

让整个博客具有类似现代高端开发者社区、科技产品官网的交互体验。

重点不是动画数量，而是动画的细节、节奏、连贯性和品质。
